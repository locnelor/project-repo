# 技术选型

## 选型原则

Qiyun-Repo 的技术选型遵循以下原则：

- **稳定性优先**：选择成熟稳定的技术方案，确保长期可维护性
- **生态完善**：优先选择生态系统完善、社区活跃的技术
- **开发效率**：注重开发体验和构建性能
- **团队适配**：考虑团队技术栈熟悉度和学习成本
- **未来兼容**：保持技术栈的前瞻性和可扩展性

## 核心技术栈

### 🏗️ 项目架构

#### Monorepo 架构

- **选择理由**：统一管理多个相关项目，共享代码和配置，提高开发效率
- **优势**：
  - 代码复用和共享
  - 统一的依赖管理
  - 原子化的版本发布
  - 简化的构建和部署流程

#### pnpm

- **版本**：最新稳定版
- **选择理由**：高效的包管理器，完美支持 Monorepo
- **优势**：
  - 节省磁盘空间（硬链接机制）
  - 更快的安装速度
  - 严格的依赖管理
  - 原生支持 workspace

#### Turbo

- **版本**：最新稳定版
- **选择理由**：高性能的构建系统，专为 Monorepo 设计
- **优势**：
  - 智能缓存机制
  - 并行构建优化
  - 增量构建支持
  - 简化的任务编排

### 🚀 前端框架

#### Vue 3

- **版本**：3.x 最新稳定版
- **选择理由**：现代化的前端框架，性能优异，开发体验良好
- **核心特性**：
  - Composition API
  - 更好的 TypeScript 支持
  - 更小的包体积
  - 更快的渲染性能

#### TypeScript

- **版本**：5.x 最新稳定版
- **选择理由**：提供类型安全，提高代码质量和开发效率
- **优势**：
  - 静态类型检查
  - 更好的 IDE 支持
  - 重构安全性
  - 自文档化代码

#### Vite

- **版本**：5.x 最新稳定版
- **选择理由**：下一代前端构建工具，开发体验极佳
- **优势**：
  - 极快的冷启动
  - 热模块替换（HMR）
  - 原生 ES 模块支持
  - 丰富的插件生态

## 前端生态

### 🧭 路由管理

#### Vue Router

- **版本**：4.x 最新稳定版
- **选择理由**：Vue 官方路由解决方案，与 Vue 3 完美集成
- **特性**：
  - 声明式路由配置
  - 嵌套路由支持
  - 路由守卫机制
  - TypeScript 支持

### 🗄️ 状态管理

#### Pinia

- **版本**：2.x 最新稳定版
- **选择理由**：Vue 官方推荐的状态管理库，替代 Vuex
- **优势**：
  - 更好的 TypeScript 支持
  - 模块化设计
  - 开发工具支持
  - 更简洁的 API

### 🎨 UI 组件库

#### Ant Design Vue

- **版本**：4.x 最新稳定版
- **选择理由**：企业级 UI 组件库，组件丰富，设计规范
- **特性**：
  - 丰富的组件生态
  - 完善的设计语言
  - TypeScript 支持
  - 主题定制能力

## 样式方案

### 🎨 CSS 框架

#### TailwindCSS 3.x

- **版本**：3.x 最新稳定版
- **选择理由**：实用优先的 CSS 框架，开发效率高
- **为什么选择 v3 而非 v4**：
  - **浏览器兼容性**：v3 对老版本浏览器支持更好，v4 在某些浏览器上存在兼容性问题
  - **生态稳定性**：v3 生态更加成熟，插件和工具支持更完善
  - **迁移成本**：v3 到 v4 的迁移成本较高，v3 已能满足当前需求
  - **团队熟悉度**：团队对 v3 更加熟悉，可以避免学习成本

- **优势**：
  - 原子化 CSS 类
  - 高度可定制
  - 优秀的开发体验
  - 自动清除未使用样式

- **ESLint**：JavaScript/TypeScript 代码检查工具
